Design and build a complete corporate landing page for LIRN company.

The website must combine two visual directions:

1. Luxury Editorial
2. Minimalist Corporate

The result should feel premium, sophisticated, executive, modern, trustworthy and highly professional.

The design should NOT look like a generic SaaS landing page, startup template, or conventional corporate website. Avoid excessive cards, excessive gradients, colorful illustrations, oversized rounded containers, generic icons, and visually noisy layouts.

The website should communicate:
- Authority
- Trust
- Sophistication
- Experience
- Precision
- Innovation
- Exclusivity
- Corporate credibility

==================================================
VISUAL DIRECTION
==================================================

Use a refined editorial composition inspired by premium consulting firms, investment firms, architecture studios, executive companies and high-end corporate brands.

Use generous whitespace and strong visual hierarchy.

Typography should be one of the main design elements.

Use:
- A sophisticated serif typeface for major editorial headlines.
- A clean modern sans-serif typeface for navigation, body text, labels and supporting information.
- Large typography with carefully controlled line height.
- Strong contrast between headings and supporting text.

Color palette:
- Deep navy / midnight blue
- Charcoal / near-black
- Off-white / warm white
- Soft gray
- Optional muted champagne/gold accent

Gold/champagne must be used very sparingly, only for subtle accents, lines, metadata, hover states or important details.

Do not make the website predominantly gold.

Use photography as an important visual component:
- Architectural photography
- Executive/corporate environments
- People in professional environments
- Abstract business/technology imagery
- High-quality monochromatic or desaturated imagery

Images should feel intentional, cinematic and premium rather than stock-photo-like.

==================================================
LAYOUT PRINCIPLES
==================================================

Use a strong editorial grid.

Combine:
- Full-width sections
- Asymmetric layouts
- Large typography
- Large image compositions
- Horizontal separators
- Minimal borders
- Generous margins
- Editorial numbering
- Small uppercase labels
- Large negative space

The page should feel calm and expensive.

Avoid filling every area of the screen.

Use visual rhythm by alternating between:
- Dark sections
- Light sections
- Large imagery
- Typography-focused sections
- Data/metrics sections
- Case studies

Animations should be subtle and sophisticated:
- Smooth fade-in
- Slight vertical movement
- Image reveal
- Text reveal
- Elegant hover transitions
- Smooth scrolling

Do NOT use flashy animations, excessive parallax, bouncing elements or distracting effects.

==================================================
LANDING PAGE STRUCTURE
==================================================

Create a complete landing page with the following sections.

01. NAVIGATION

Minimal and elegant navigation.

Include:
- Company logo
- About
- Services
- Approach / Methodology
- Projects / Experience
- Insights
- Contact

Use a transparent navigation over the hero when appropriate.

The navigation should become solid/sticky when scrolling.

Include a discreet CTA such as:
"Let's talk"
or
"Contact us"

02. HERO SECTION
==================================================

Create a visually dominant hero section.

Use either:
- A full-screen architectural/corporate image with a dark overlay
OR
- A deep navy/black background with a sophisticated abstract visual.

Include:
- Small eyebrow/label
- Large editorial headline
- Short supporting paragraph
- Primary CTA
- Secondary text link if appropriate

CHALLENGES.

The headline should be large, confident and concise.

Do not overload the hero with information.

==================================================
RESPONSIVE DESIGN
==================================================

The website must be fully responsive.

Desktop:
- Strong editorial grid
- Large typography
- Asymmetric compositions
- Large imagery
- Generous whitespace

Tablet:
- Preserve hierarchy while reducing spacing and typography.

Mobile:
- Simplify the editorial compositions.
- Maintain large typography but avoid excessive text wrapping.
- Convert complex layouts into vertical sections.
- Make navigation compact.
- Ensure all CTAs are easy to access.
- Maintain the premium aesthetic.

==================================================
UX PRINCIPLES
==================================================

The website should feel:
- Premium
- Calm
- Intentional
- Sophisticated
- Executive
- Modern

Every visual element must have a purpose.

Prioritize:
1. Typography
2. Composition
3. Photography
4. Whitespace
5. Content hierarchy
6. Subtle interaction

Avoid:
- Excessive cards
- Excessive rounded corners
- Generic SaaS layouts
- Excessive gradients
- Bright colors
- Decorative illustrations
- Stock-looking imagery
- Excessive shadows
- Excessive animations
- Dense sections
- Generic icon grids

The final result should look like a premium corporate brand website designed by a high-end digital agency, not like a prebuilt template.
