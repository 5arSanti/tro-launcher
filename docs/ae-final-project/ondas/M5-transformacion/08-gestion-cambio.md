## 2. Tratamiento de cambios

1. Se registra la solicitud de cambio con origen, dominio y claves afectadas.
2. Se clasifica: simplificación, incremental o reformulación de la arquitectura.
3. Santiago aprueba o rechaza.
4. Si se aprueba, se actualizan todos los textos que usan la clave afectada y el registro de empresa.
